# TimeDays Legal Pages

Public GitHub Pages repository hosting the Privacy Policy, Terms of Use, and Support pages for **时光纪念 (TimeDays)**.

## Publish on GitHub Pages
1. Create a **Public** repository named `TimeDays-Legal` under your GitHub account (`chihuanqi`).
2. Push this repo:
   ```bash
   git remote add origin git@github.com:chihuanqi/TimeDays-Legal.git
   git push -u origin main
   ```
3. In GitHub repo **Settings → Pages → Branch**, select `main` and `/ (root)`, then click **Save**.
4. Live URLs:
   - Privacy Policy: `https://chihuanqi.github.io/TimeDays-Legal/privacy.html`
   - Terms of Use: `https://chihuanqi.github.io/TimeDays-Legal/terms.html`
   - Support URL: `https://chihuanqi.github.io/TimeDays-Legal/support.html`
